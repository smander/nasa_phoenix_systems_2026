# Button

Buttons: `primary` (filled `fg` on `bg`, e.g. *See results →*) and `quiet` (panel fill, `line-2` border).

Provide `variant`, `children`, optional `icon`, standard button props. Min height `touch-min`. Press scales to .97. Disabled at 45% opacity — always give a `title` that explains why ("Up to 8 points can be compared").
