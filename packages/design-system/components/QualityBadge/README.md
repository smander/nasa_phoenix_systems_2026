# QualityBadge

The coordinate-quality badge: region centre, exact point, approximate, custom.

Provide `quality` and, for approximate, a `source` (shown as tooltip: "Digitised from NASA map, Oct 2024 list"). `label` overrides the text ("custom point, terrain 480 m").

- Approximate is dashed with a ≈ glyph — it must stay visible wherever an approximate point appears.
