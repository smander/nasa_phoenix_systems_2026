# Terminal

The SPL model and `saple analyze` output in a CLI frame. Dark in both themes (`term-*`).

Provide `title` (file name), `code` (pre-highlighted nodes: `.k` keywords, `.t` ticks, `.c` comments), `output` (lines; ✓ lines turn `term-ok`, ✗ lines `term-err`), `typeOn` + `runKey` (lines type in at 260ms with a blinking caret; bump `runKey` to replay), `preview` (adds the honest "preview" tag), `collapsed` + `summary` + `summaryNote` (wraps it in a closed "Show the formal proof" disclosure — the default outside Plan-mode deep dives).
