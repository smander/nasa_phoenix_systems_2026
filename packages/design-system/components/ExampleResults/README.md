# ExampleResults

A full Step 2 results screen built only from this system — Malapert Massif at Jan 16, 2027 16:00 UTC in Plan mode — showing how the pieces compose: app bar, point header, SkyHero with scrubber, four readouts, day-by-day panels, ranking with month bars, and the SAPLE mission check.

It is a showcase page, not a component to import. Click Jan 9 in the landing-date strip to watch SunlitStay and BatterySafe fail: the red marker pings on the mission lane, the battery curve drops through "empty", and the terminal re-runs with ✗ lines. Ranking and readout numbers are the real January 2027 values from the brief; month-bar segment order in the ranking is approximate.
