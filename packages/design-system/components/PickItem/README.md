# PickItem

A selectable landing point in the Step 1 list: name, quality badge, metadata, Sun % / Earth %, and its month bar.

Provide `name`, `quality` + `source`, `meta` (group · lat, lon · elevation), `sun`, `earth`, `segments`, `selected`, `onClick`.

- Selected = `sun` outline (1px border + 1px inset). Hover lifts 1px.
- Coordinates and numbers use tabular figures; signed with true minus.
